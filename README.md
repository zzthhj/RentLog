## English

### 1. Overview

RentLog is a landlord record-keeping tool. Rental business data you enter — properties, tenants, leases, payments, photos, and PDFs — is stored on your device. We do not operate a cloud account for that data and do not automatically sync it to our servers.

### 2. Local Storage and Backups

All property, tenant, financial, photo, and PDF records stay on your device unless you export them. Backup & Restore and tenant-archive export run only when you start them. You choose where those files go. We cannot read your backups.

### 3. Anonymous Usage Statistics

To improve the product, RentLog records anonymous feature-use and purchase-funnel events through the third-party service Aptabase — for example which tool you used, a duration range, whether the paywall was opened, or whether a purchase completed. Events use only fixed options and time ranges. They do not include rental records, document contents, personal identity, or a device identifier. If you install after tapping an App Store ad, Apple’s official attribution interface may return source details such as the ad keyword and country, used only to understand ad performance. None of these statistics can be linked to you. You can disable reporting by restricting the app’s network access in system settings.

### 4. Device Permissions

Camera, Photo Library, and Face ID / Touch ID (if you enable them) are used only on-device for inspections, imports, and unlocking the app.

### 5. No Account, No In-App Ads

You do not need an account. RentLog shows no third-party advertisements inside the app.

## Español

### 1. Descripción general

RentLog es una herramienta de registro para propietarios. Los datos de alquiler que introduce se guardan en su dispositivo. No operamos una cuenta en la nube para esos datos ni los sincronizamos automáticamente con nuestros servidores.

### 2. Almacenamiento local y copias

Registros de propiedades, inquilinos, finanzas, fotos y PDF permanecen en el dispositivo salvo que usted los exporte. Las copias de seguridad y el archivo del inquilino se crean solo cuando usted las inicia.

### 3. Estadísticas de uso anónimas

Para mejorar el producto, RentLog registra a través del servicio de terceros Aptabase eventos anónimos de uso de funciones y del embudo de compra: por ejemplo qué herramienta usó, un intervalo de duración, si abrió la pantalla de pago o si completó una compra. Los eventos solo incluyen opciones fijas e intervalos de tiempo; no incluyen registros de alquiler, contenido de documentos, identidad personal ni un identificador del dispositivo. Si instala tras pulsar un anuncio de App Store, la interfaz oficial de atribución de Apple puede devolver datos de origen como la palabra clave y el país, solo para medir el rendimiento publicitario. Ninguna de estas estadísticas puede asociarse a usted. Puede desactivar el envío restringiendo el acceso a la red de la app en Ajustes.

### 4. Permisos

Cámara, fotos y Face ID / Touch ID se usan solo en el dispositivo.

### 5. Sin cuenta ni anuncios dentro de la app

No se requiere cuenta. RentLog no muestra anuncios de terceros dentro de la app.
